# 题前基础基线：正规定义 → 术语祛魅 → 当前题映射

这份 reference 用来执行“3补”的前两补：**数据结构基线 + 算法原语基线**。

目标不是只让用户“听懂一个比喻”，也不是让用户背教材定义，而是建立一座稳定的桥：

> **专业世界里的准确概念 → 白话操作直觉 → 当前 LeetCode 题里的具体角色**

原则：每次只补当前题需要的最小闭环，通常 60–180 秒。已熟练内容自动缩短。

---

# 一、统一讲法：五层祛魅卡

首次遇到一个关键结构/算法时，按顺序讲：

1. **正规定义**：1–2 句，术语准确；
2. **祛魅**：不用新术语，用操作/生活语言说“它其实就在干嘛”；
3. **当前题映射**：题目里的什么，对应这个结构里的什么；
4. **本题操作与复杂度**：只讲现在会用到的动作；
5. **微型例子**：3–6 个元素手推。

最后必须回答一句：

> **“所以这道题为什么偏偏需要它？”**

如果不能回答这一句，说明还停留在背名词。

# 二、数据结构基线

## 1. Python list / 动态数组

**正规定义**：数组是一种按连续逻辑下标组织元素的线性数据结构；Python 的 `list` 是动态数组实现，可以自动扩容。

**祛魅**：就是一排有编号的格子。你知道第几个格子，就能直接伸手拿。

**当前题映射**：LeetCode 里的 `nums` 往往就是这排格子，`i` 是格子编号，`nums[i]` 是格子里的值。

本题常用：
- `nums[i]`：按下标读取，O(1)；
- `nums.append(x)`：末尾加入，摊销 O(1)；
- 遍历：O(n)；
- `x in nums`：一般要扫，O(n)。

微例：`[4, 7, 1]` 中 `nums[1] == 7`。

**关键直觉**：按位置找很快；按值问“它在哪/在不在”通常不快。这经常引出哈希表。

## 2. dict / 哈希表

**正规定义**：哈希表（hash table）是一种实现键值映射的数据结构。它通过哈希函数把 key 映射到内部存储位置；在平均情况下，查询、插入和删除可以做到 O(1)。Python 的 `dict` 是哈希表的一种实现。

**祛魅**：把它当成一本“快速通讯录”。你拿一个 key 去问，它能很快告诉你：见没见过？如果见过，对应的信息是什么？

**当前题映射（两数之和）**：
- `key` = 已经扫过的数字；
- `value` = 这个数字出现的下标；
- `need in seen` = “我现在需要的另一半以前出现过吗？”；
- `seen[x] = i` = “把当前数字和它的位置记进通讯录”。

常用：
- `d[key] = value`；
- `key in d`；
- `d[key]`；
- `d.get(key, default)`。

平均查询/插入 O(1)，额外空间通常 O(n)。

微例：`{2: 0, 7: 1}` 表示数字 2 在下标 0，数字 7 在下标 1。

**所以为什么需要它？** 当暴力算法反复扫描“某个值以前出现过没有”时，哈希表用额外空间把这类查询从 O(n) 降到平均 O(1)。

> 初学阶段不必先深挖哈希冲突、负载因子、扩容；等这些机制影响题目或用户追问时再补。

## 3. set / 哈希集合

**正规定义**：集合（set）保存互不重复的元素，并支持成员查询；Python 的 `set` 通常基于哈希表实现，平均成员查询/插入为 O(1)。

**祛魅**：如果 `dict` 是“名字 → 电话”的通讯录，`set` 就只有“这个名字在不在名单里”，不附带电话。

**当前题映射**：当题目只需要知道“某值是否出现过”，而不需要保存它的下标/次数/其他信息时，`set` 往往更贴切。

常用：`x in seen`、`seen.add(x)`、`seen.discard(x)`。

## 4. 栈 Stack

**正规定义**：栈是一种后进先出（LIFO, Last In First Out）的线性数据结构，只在同一端进行主要插入和删除。

**祛魅**：像摞盘子：最后放上去的盘子最先拿走。

**当前题映射**：栈里常放“最近遇到、但答案还没确定”的东西，如左括号、等待找到下一个更大元素的下标。

Python 常用 `list`：`append()` 入栈，`pop()` 出栈，`stack[-1]` 看栈顶。

## 5. 队列 Queue

**正规定义**：队列是一种先进先出（FIFO, First In First Out）的线性数据结构，一端入队、另一端出队。

**祛魅**：排队买票，先来的人先处理。

**当前题映射**：BFS 里，队列保存“已经发现、等待按发现顺序继续向外扩展”的节点。

Python 用 `collections.deque`：`append()` 入队，`popleft()` 出队。避免高频 `list.pop(0)`，它通常是 O(n)。

## 6. 链表 Linked List

**正规定义**：链表是一种由节点构成的线性数据结构；每个节点保存数据以及指向下一节点（双链表还包括前驱）的引用，节点在内存中无需连续存放。

**祛魅**：不是一排连续格子，而是一串“纸条”：每张纸条写着自己的值，以及“下一张纸条在哪”。

**当前题映射**：
- `cur` = 你手里当前拿着哪张纸条；
- `cur.next` = 下一张纸条；
- `cur.next = prev` = 真正改掉箭头方向。

LeetCode Python 常见：
```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

核心：Python 里优先讲**对象引用**，不默认套 C++ 裸指针话术。

## 7. 树 Tree

**正规定义**：树是一种层次型非线性数据结构，由节点和父子关系构成；二叉树中每个节点最多有两个孩子。

**祛魅**：像文件夹目录或家谱：一个节点下面继续分叉。

**当前题映射**：`root` 是当前节点，`root.left/right` 是它下面的左右分支。

递归题必须先问：这个函数接收一个节点后，承诺返回“这棵子树”的什么信息？

## 8. 图 Graph / 网格

**正规定义**：图由顶点（vertex）和边（edge）构成，用来表示任意对象之间的连接关系；网格题常可把每个格子看成顶点、上下左右关系看成边。

**祛魅**：一张“谁和谁能直接走到”的关系网。

**当前题映射**：节点是当前位置，邻居是下一步能到的位置；`visited` 是“已经去过，别重复绕回来”的记录。

## 9. 堆 Heap

**正规定义**：堆是一种满足堆序性质的完全树形结构，使最小元素或最大元素可以快速位于堆顶；Python `heapq` 提供最小堆。

**祛魅**：它不是把所有东西完整排好序，而是始终替你把“当前最小的那个”顶到最前面。

**当前题映射**：Top K 场景中，堆帮助你只维护最有希望留下的 k 个候选，而不必完全排序全部元素。

常用：`heappush`、`heappop`、`heap[0]`。

# 三、算法原语基线

## 1. 双指针 Two Pointers

**正规定义**：双指针是一类利用两个索引/引用协同遍历数据、通过指针移动来压缩搜索空间或维护关系的算法技巧。

**祛魅**：不是“写两个变量”就叫双指针，而是让两个位置合作，一次移动就排除一批不可能答案。

**当前题映射**：必须明确两个指针各自代表什么，以及为什么移动某一端不会漏解。

## 2. 滑动窗口 Sliding Window

**正规定义**：滑动窗口是一类在连续区间上维护可增量更新状态的算法技巧，通过移动左右边界避免对每个区间重新计算。

**祛魅**：拿一个可伸缩的框罩住数组/字符串；右边吃进一个，必要时左边吐出一个，框里的统计量顺手更新。

**当前题映射**：必须定义 `[l, r]` 表示什么、合法条件、何时扩、何时缩。

## 3. 前缀和 Prefix Sum

**正规定义**：前缀和通过预处理 `prefix[i]` 保存起点到位置 i 的累计结果，使后续区间和可由两个前缀结果相减得到。

**祛魅**：把“从头到这里一共多少”提前记账，以后问某一段就不用重算整段。

## 4. 二分查找 Binary Search

**正规定义**：二分查找利用有序性或单调判定，每一步把候选空间缩小约一半，典型复杂度 O(log n)。

**祛魅**：像猜数字，每次根据“大了/小了”直接扔掉一半答案。

**当前题映射**：必须指出哪一个量具有单调性，以及当前判断为什么允许安全丢掉一半。

## 5. DFS / 深度优先搜索

**正规定义**：DFS 是图/树遍历策略之一：沿一条分支尽可能深入，无法继续后再回退探索其他分支。

**祛魅**：走迷宫时先认准一条路一直走到底，碰壁再回来换岔路。

**当前题映射**：要说清递归函数语义、终止条件、当前层动作、返回值。

## 6. BFS / 广度优先搜索

**正规定义**：BFS 是按距离/层次从近到远访问图中节点的遍历策略，通常借助队列实现。

**祛魅**：水波从起点一圈一圈向外扩散。

**当前题映射**：无权图中若按层扩张且访问规则正确，第一次到某节点通常就是最少步数。

## 7. 回溯 Backtracking

**正规定义**：回溯是一种系统搜索解空间的算法，在部分选择无法继续或完成后撤销当前选择，再尝试其他分支。

**祛魅**：做选择题树：选一个 → 往下试 → 回来擦掉 → 换另一个。

**当前题映射**：明确 `path`、候选集合、结束条件、撤销动作、去重策略。

## 8. 动态规划 Dynamic Programming

**正规定义**：动态规划通过把具有重叠子问题和最优子结构的问题分解成状态，并保存子问题结果，从而避免重复计算。

**祛魅**：不是神秘公式；就是先把“一个小问题的答案到底代表什么”定清楚，然后把已经算过的小答案留着给大问题复用。

**当前题映射**：固定顺序：定义 `dp[...]` → base case → 状态转移 → 计算顺序 → 最后才考虑压缩空间。

## 9. 单调栈 Monotonic Stack

**正规定义**：单调栈是在栈内维持元素（或对应值）单调递增/递减关系的一类技巧，用于高效处理最近/下一个更大或更小元素等问题。

**祛魅**：栈里只留下“还值得继续等答案的人”；新元素一来，可能一口气替几个旧元素结算。

**当前题映射**：先说清栈存值还是索引、单调方向、何时弹栈、弹出意味着谁的答案被确定。

# 四、基线的自适应长度

- 掌握度 0：完整“正规定义 → 祛魅 → 映射 → 操作 → 微例子”；
- 掌握度 1：保留定义 + 当前题映射 + 微例子；
- 掌握度 2：20–40 秒快速复习；
- 掌握度 3：一句提醒，然后开题；
- 掌握度 4：通常不主动重复，除非出现新边界/新角色。

目的不是永远“先上课”，而是让这些曾经高大上的名字，逐渐变成你脑子里能直接拿起来用的工具。
