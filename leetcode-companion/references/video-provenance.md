## 视频内容 vs Skill 扩展

### 直接承接视频的核心
- 拿题先观察，而不是先写代码；
- 用题目特征识别高频 Pattern；
- 建立 Pattern 化的刷题经验地图；
- 系列化地用具体题巩固模式。

### 为用户学习目标新增的机制
这些是 Skill 的教学设计，不声称是视频作者逐字提出：
- 朴素解 → 瓶颈 → 优化的推导链；
- 数据规模 → 复杂度预算；
- Micro Foundation Patch（按真题就地补数据结构）；
- 6 层提示阶梯；
- 自动判断 Foundation / Recognition / Modeling / Implementation 等薄弱点；
- 自动 Take-away 提取；
- 0–4 掌握度；
- 1/3/7/21 天复习与近邻迁移；
- 根据薄弱点自动挑下一道 Hot100。

## 为什么做这些扩展

因为单纯“知道 15 个 Pattern”对基础薄弱的初学者还不够。真正的难点通常是：

- 不知道为什么这题属于某 Pattern；
- 不知道 Pattern 中每个变量代表什么；
- 基础数据结构操作不熟；
- 看懂过但无法独立复现；
- 做完没有把错误变成长期经验。

因此，本 Skill 的主体不是“Pattern 名词表”，而是一套会从真实对话里自动提取经验的学习闭环。
